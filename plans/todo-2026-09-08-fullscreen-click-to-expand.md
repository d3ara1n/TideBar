# 全屏默认点击展开

## 目标与范围

- 全屏默认行为为 Click to Expand / 点击展开。
- 鼠标靠近不展开；用户点击汐线周围的紧凑区域才展开。
- 汐线视觉为 160×3pt，点击窗口为 184×16pt，左右各加 12pt，底边贴屏幕底边。
- 点击区域外继续由系统向底层应用分发事件；不使用全局点击拦截或事件转发。
- 展开后沿用普通交互与离场收起，收起后再次要求点击；收起时快捷键不能绕过点击门槛。
- 正常显示、完全隐藏以及既有 AX 全屏检测保持其定义。

## 实现

- [x] `FullscreenBehavior.clickToExpand` 为默认值，已保存的 normal / hidden 保持生效。
- [x] 独立非激活 `TidelineClickPanel` 接收左键按下/松开，在区域内松开后展开。
- [x] 只在进入点击模式时收起，后续轮询不撤销已点击展开的状态。
- [x] 展开、完全隐藏、退出全屏、面板重建及停用时撤销点击窗口。
- [x] 双语标签、设置说明与决策文档同步。
- [x] `swift build`、`swift build --build-tests` 和 `git diff --check` 通过；验证用例仅编译，GUI 由用户运行验收。
- [x] 点击时序、事件边界、状态切换和生命周期代码审查完成，未发现实际缺陷。

## 用户运行验收

- [ ] 在全屏棋牌游戏等场景中，将鼠标移动到底部及汐线附近不展开；点击紧凑区域外的牌不展开也不丢点击。
- [ ] 点击汐线及其附近少量容错区域能够展开；按住后移出区域松开不展开。
- [ ] 展开操作本身不误启动图标；展开后可操作应用和潮涌，移开后正常收起，停留在附近不会自动重开。
- [ ] 收起时快捷键不打开图标栏；点击打开后键盘导航可用。
- [ ] 三档切换及全屏进出后，没有遗留不可见点击区域；正常显示可悬停展开，完全隐藏无入口。
- [ ] 在不同缩放比例和外接屏上，184×16pt 的点击容错舒适且不干扰底部游戏操作。
