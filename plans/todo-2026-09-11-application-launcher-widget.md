# 应用收藏夹小工具

> 状态：已实现核心路径并通过一轮 UI 重构（本地化、外观双色路、尺寸归 Layout、设置页范式对齐），`swift build` 与 99 项测试通过；待用户 GUI 验收。

## UI 基线（2026-09-11 重构后）

- 栏内条目：widget 通过 `ItemBehaviorProviding.barArtwork` 自产 artwork；应用收藏夹为内容前 4 应用的 2x2 缩略网格（单应用居中、空态类型符号），占普通图标槽。悬停/选中特效由 `ItemBarArtwork.usesSharedHoverEffects` 决定，widget 可关闭共享特效完全自绘。
- 潮涌体：面板尺寸固定（`Layout.launcher*`），网格内部滚动；词条全走 Runtime 表且 draw 时解析；颜色分玻璃/回退双路；标题默认只读，点头部铅笔按钮进入编辑（Enter 提交、Esc 取消）；空态占位、脚注提示、内部排序落点指示齐备。
- 设置页：小工具行与固定项目行同范式（悬停 ×、拖把、右键），添加入口为类型卡片 sheet；新实例默认名随界面语言。

## 交付范围

- `kind == widget` 的 TideBar item 作为小工具实例唯一真值；不另建 widget 列表或存储。
- 首个小工具类型为应用收藏夹，可创建多个独立实例。
- 实例名称与应用引用列表封装在 widget payload 内，实例之间允许重复收藏同一应用。
- 设置页新增「小工具」页面，仅负责添加、排序、移除实例；移除需确认并清除实例 payload。
- 应用收藏夹点击 TideBar 条目直接打开潮涌；潮涌内显示可滚动应用网格。
- 潮涌内支持启动应用、拖入 `.app`、拖拽排序、拖出移除、右键移除和标题改名。
- 外部 `.app` 可拖到 TideBar 小工具条目或其潮涌面板；TideBar 内部应用条目可拖入小工具。
- 小工具栏展示使用独立内容宿主和动态宽度；不显示应用运行点、角标或窗口状态。
- `setActive` 生命周期已接入栏展开/收起，为未来天气、时钟等动态小工具暂停/恢复刷新预留接口。

## 未包含

- 天气、时钟等其他具体小工具。
- 搜索、分组和统一小工具设置页面。
- 外部插件动态加载框架。

## GUI 验收重点

- 设置页添加多个应用收藏夹、排序和移除确认。
- 多实例名称、应用列表和顺序重启后保持；删除一个实例不影响其他实例。
- TideBar 小工具条目宽度、点击展开、潮涌滚动与标题编辑。
- Finder `.app` 拖入图标/潮涌；TideBar 应用条目拖入潮涌。
- 潮涌内排序、拖出移除、右键移除和点击启动。
- 普通 TideBar 应用条目的窗口点、角标、快捷键和既有拖拽不回归。
