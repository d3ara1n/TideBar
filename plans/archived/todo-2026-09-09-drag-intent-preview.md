## 用户反馈与范围

- 已确认排序、拖入固定、取消固定和外部文件移入目录可用。
- 成功拖出移除不能飞回原位置；采用原地消失，不实现粒子粉碎或额外动画窗口。
- 排序需要让位占位；接收需要图标本身高亮，不能与普通 hover 圆环混淆。
- 展示语义／布局与视觉样式分离，后续换样式不改资源操作或提交规则，不引入主题／插件框架。

## 实现地图

| module | Interface 与职责 |
|---|---|
| `Sources/TideBarCore/ItemDragLayout.swift` | `ItemDragPreview` 不携带资源，只表达展示意图；`ItemDragLayout` 产生身份槽位与归一化命中区间；`ItemDragHitLatch` 维护屏幕坐标下的短期命中容错。无 AppKit 或文件操作依赖 |
| `Sources/TideBar/ItemRowView.swift` | 真实条目与临时槽位分开；身份差分、几何换算、源图标拿起、邻项让位、当前 presentation 位置接续，统一协调清理 |
| `Sources/TideBar/ItemDragVisuals.swift` | 占位形状／数量、图标不透明像素上的提亮或压暗、普通 hover 抑制与让位动画的样式入口；不读取 pasteboard、类型行为或固定配置 |
| `Sources/TideBar/Motion.swift` | 拖拽反馈和让位的时长、弹性，复用全局速度与减少动态效果规则 |
| `Sources/TideBar/ItemDragCoordinator.swift` | 会话开始即禁止原生失败回位；共享 source 生命周期通知，不依赖图标按钮存活。沿用来源校验、目标提案和安全提交 |
| `Sources/TideBar/TideBarView.swift`、`TideBarController.swift` | 目标事件适配、逐屏生命周期、预览宽度调整；不解释样式或资源 payload |

## 交互规则

- 内部拖拽的图像不飞回；取消／未知结束撤销投射并恢复源图标，不更改数据，也不播放删除特效。
- 重排从视觉上拿起源图标，在目标位置提供一格占位，邻项让位；松手后才提交固定／会话顺序。
- 外部关联创建使用成组占位；数量表示输入引用数，不声称去重后的新增记录数。面板为预览按需扩一格，保留屏幕宽度上限。
- 接收不生成占位、不画外圈；目标 artwork 提亮，拒绝则压暗并沿用系统拒绝光标，不退化成插入。
- 拖拽期间抑制普通 hover 圆环与位移；普通非拖拽 hover 保持既有行为。
- 命中读取逻辑目标布局，不追逐弹簧动画的位置。占位是明确插入区；布局变化时保留已命中的区域并容纳新位置，光标进入真实新位置后释放旧容错区，避免占用相邻空隙。
- 列表身份变化会撤销旧命中容错；退出目标、结束／取消、收起、重建和上下文失效均清理预览。源图标状态可跨收起／重建同步。
- 不改变来源权限、引用语义、目录移动、保守终止策略或全屏展开门槛。
