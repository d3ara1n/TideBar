# 应用通用右键菜单

> 结束 2026-09-02；应用级动作入口已完成，菜单结构由 `todo-2026-09-02-app-management-menu.md` 接续。

## 背景

macOS 没有公开 API 可供第三方进程读取任意应用通过 `applicationDockMenu(_:)` 提供的完整 Dock 菜单。系统 Dock 可以代理该菜单，但 Dock 替代品只能自行构建稳定能力范围内的菜单。

TideBar 当前已提供窗口直达、固定切换、退出和在 Finder 中显示，但固定且未运行的应用缺少显式“打开”，运行中的应用缺少“隐藏”。

## 范围

- 当前只实现通用应用菜单：窗口直达、打开/激活、隐藏、固定切换、退出、在 Finder 中显示。
- 未运行应用显示“打开”，运行应用显示“隐藏”。
- 退出和隐藏均通过应用级动作入口执行，并在执行前刷新模型、校验应用身份。
- 保持 Finder 不可退出等既有行为能力约束。

## 未来可选

以下能力不纳入当前实现，需重新立项后才能加入：

- 最近项目及其文档图标。
- 针对浏览器、播放器等应用的专属菜单适配。

不读取未公开的 Shared File List 文件，不抓取系统 Dock 的瞬态 AX 菜单，不使用 Dock 私有 API，也不承诺继承任意应用的自定义 Dock 菜单。

## 验收

- 固定且未运行的应用菜单提供“打开”，点击后通过现有启动路径打开应用。
- 运行中的应用菜单提供“隐藏”，点击后隐藏该身份对应的有效运行实例。
- 窗口直达、固定切换、退出和在 Finder 中显示保持可用。
- Finder 菜单仍不显示“退出”。
- `swift build` 通过。
