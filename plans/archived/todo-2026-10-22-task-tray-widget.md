# 任务托盘小工具

## 范围

用户确认：文件路径投递后形成任务；转换在同目录按同名新后缀输出，重名编号；移除隔离标记不产生新文件。潮涌体选择本次操作，图标直投使用显式设置的默认操作。图标显示计数 badge 与进度。

内置操作为图片转 JPEG、转 PNG、移除隔离标记。不引入第三方依赖或任意 shell 命令执行入口。

## 人工验收清单

以下保留为回归检查清单，不代表每一项均已逐项验证；agent 完成编译和静态检查，运行验收来自用户反馈。

通过 `swift run --build-system native` 运行，在设置 → 小工具中添加任务托盘。

1. 首次拖图片到小图标：仅暂存，打开潮涌；选择转换操作并执行。点击星标后，后续图标直投立即执行。
2. 潮涌切换操作／修改 JPEG 质量不影响图标默认值；关闭重开回到默认配置。
3. 单张、批量图片转换；源文件不变，输出旁置，已有同名结果自动加编号。JPEG 透明区域铺白；动画／多页图片显示明确错误。
4. 以可丢弃样本检查去隔离标记：文件、应用包／目录、无标记、无权限、子目录符号链接。只删除隔离属性，不生成副本；部分失败保留记录。
5. 多文件排队显示未结束数量与完成个数进度；关闭潮涌后继续，重新打开看到结果；重试与清除记录不误删文件。
6. 下拉菜单可点选，文件选择器与其 Esc 不误关潮涌；直接拖入、再次投递、多显示器、浅深色、减少动态效果。
7. 应用收藏夹的创建、添加应用与改名没有回归；拖动栏内应用到任务托盘不执行文件操作。
8. 非 JPEG 操作不留质量滑块空位，任务区域按实际条数增高（至三行后滚动），检查说明文案与底部按钮不截断。
9. 保存默认操作与图标投递后，分别核对默认值已保存、去标记任务实际成功。`sandbox_extension_consume failed: 22` 已确认旧安装版本也存在，新开发版本仍可复现，独立跟踪见 [sandbox consume 日志](../todo-2026-10-22-sandbox-consume-log.md)；书签选项变更未消除该日志。

## 边界

- 任务及待选路径只在本次应用运行期间保留，重启不恢复；正式应用持久化默认配置，开发运行沿用内存覆盖、不写正式配置的项目约定。
- 结果文件通过“在 Finder 中显示”定位；结果拖出、持久化任务恢复及更多操作均不属于本次范围，若立项需另行确认契约。
