# 应用异步启动与反馈

## 范围

- 收藏夹通过异步 NSWorkspace API 打开应用，等待期间保持面板可操作，支持并行打开多个应用。
- 冷启动立即显示图标 pulse 与向外淡出的图标残影；栏内固定应用复用同一启动状态与动画。
- 系统确认启动、激活、已有窗口或启动完成时结束反馈；失败或五秒超时同样结束，超时不取消系统启动。
- 收藏夹本次全部启动反馈结束后自动关闭；主动关闭立即生效，旧请求不能关闭后续面板。
- 已运行应用继续激活／切窗，不循环播放启动动画；减少动态效果使用静态反馈。

## 验证

- agent 执行 `swift build --build-system native` 并检查并行请求、重复点击与迟到回调的生命周期。
- 用户运行验收：慢启动、连续启动两个应用、等待时关闭并重开收藏夹、已有应用、五秒超时与减少动态效果。

## 状态

- 实现完成，`swift build --build-system native` 与 diff 检查通过，用户已确认合入。
- 并行启动时首个应用激活后，验收收藏夹仍可接收 Esc；主动切换或点击其他应用沿用既有交互规则。
- 检查了请求代次与面板实例隔离，并修正栏内按钮闭包的自持有，确保启动通知随旧按钮释放。
