# 应用收藏夹小工具

> 状态：核心路径与交互已交付并通过用户 GUI 验收（2026-09-11，含栏内拖拽重排、潮涌编辑、悬停与主题跟随、排序边界收敛）；`swift build` 与 103 项测试通过。归档，后续演进另立案。

## UI 基线（2026-09-11 重构后）

- 栏内条目：widget 通过 `ItemBehaviorProviding.barArtwork` 自产 artwork；应用收藏夹为内容前 4 应用的 2x2 缩略网格（单应用居中、空态类型符号），占普通图标槽。应用收藏夹关闭共享悬停特效（`usesSharedHoverEffects = false`）：悬停/选中为底板变亮，无上浮、无圆环。widget 与普通条目一样参与栏内拖拽重排，拖拽跟随图截取当前 artwork；拖出栏外仅回位不删除。
- 潮涌体：面板尺寸固定（`Layout.launcher*`），网格内部滚动；词条全走 Runtime 表且 draw 时解析；颜色分玻璃/回退双路；标题默认只读，点头部铅笔按钮进入编辑（Enter 提交、Esc 取消）；空态占位、脚注提示、内部排序落点指示齐备。
- 设置页：小工具行与固定项目行同范式（悬停 ×、右键移除；排序归栏内拖拽），添加入口为类型卡片 sheet；新实例默认名随界面语言。

## 交付范围

- `kind == widget` 的 TideBar item 作为小工具实例唯一真值；不另建 widget 列表或存储。
- 首个小工具类型为应用收藏夹，可创建多个独立实例。
- 实例名称与应用引用列表封装在 widget payload 内，实例之间允许重复收藏同一应用。
- 设置页新增「小工具」页面，仅负责添加、移除实例；移除需确认并清除实例 payload。
- widget 与普通条目同序参与栏内拖拽重排（可与 app/文件/目录交错）；拖出栏外仅回位，不删除实例。
- 应用收藏夹点击 TideBar 条目直接打开潮涌；潮涌内显示可滚动应用网格。
- 潮涌内支持启动应用、拖入 `.app`、拖拽排序、拖出移除、右键移除和标题改名。
- 外部 `.app` 可拖到 TideBar 小工具条目或其潮涌面板；TideBar 内部应用条目可拖入小工具。
- 小工具栏展示使用独立内容宿主和动态宽度；不显示应用运行点、角标或窗口状态。
- `setActive` 生命周期已接入栏展开/收起，为未来天气、时钟等动态小工具暂停/恢复刷新预留接口。

## 未包含
