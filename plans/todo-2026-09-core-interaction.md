# 核心交互：细线 ↔ 图标栏

> 立案 2026-09-02。产品灵魂交互的完整实现。

## 目标

汐线在鼠标靠近时展开为图标栏，离开后收起——立住「零存在感」的核心体验。

## 范围

- [ ] 展开态视图：~64pt 高图标栏（占位灰块即可），圆角背景
- [ ] 细线 ↔ 图标栏过渡动画（NSAnimationContext / layer 动画），panel frame 随高度调整
- [ ] 收起防抖：mouse exited 后 300ms 延迟收起，期间 re-enter 取消
- [ ] 全屏 Space 检测：全屏时保持细线态
- [ ] 多屏支持：每屏一个 panel + 屏幕参数变更通知

## 验收

编译通过后由用户 `swift run` 做 UI 验证：hover 展开/收起手感、防抖不闪烁、全屏 Space 行为、多屏表现。

## 备注

防抖参数、全屏策略、多屏方案等既定约定见 `docs/decisions.md`「交互与技术约定」。
