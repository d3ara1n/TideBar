# M3：系统接管向导与应用外壳

> 立案 2026-09-02。目标是让 TideBar 具备可配置、可接管、可恢复的完整应用外壳；窗口管理功能继续在后续任务扩展。

## 目标

- [x] 应用生命周期与菜单栏入口
- [x] 首次启动向导，默认不修改系统 Dock
- [x] 统一运行模式配置：悬浮测试 / 系统接管
- [x] 设置窗口：接管、恢复、修复、辅助功能入口
- [x] Dock 配置快照、完整恢复和目标指纹校验
- [x] 接管态贴底布局（offsetY = 0）
- [x] 设置界面按需检查 Dock 状态
- [x] 漂移状态警告与手动修复
- [x] TideBar 正常退出时尽力恢复 Dock
- [x] 面板优先使用 `.statusBar` 层级，潮涌高一级

## 接管参数

`autohide=true`、`autohide-delay=1000`、`autohide-time-modifier=0`、`no-bouncing=true`、`tilesize=16`、`magnification=false`、`largesize=16`、`mineffect=scale`。

## 范围边界

- 暂不做最大化窗口避让，先接受展开态覆盖窗口。
- 暂不做废纸篓、角标、拖拽管理和实时窗口缩略图。
- 不运行常驻轮询计时器；外部配置漂移只在设置界面打开或用户主动检查时发现。
- 强制杀进程、断电和系统崩溃无法由进程内退出钩子覆盖；设置窗口保留手动恢复入口。

## 验收

编译通过后由用户通过 `swift run` 验证首次向导、状态栏菜单、接管/恢复、Dock 外部改动后的修复，以及普通窗口、全屏和多屏场景下的层级表现。
