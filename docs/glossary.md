# 产品词汇表

| 中文 | English | 含义 |
|---|---|---|
| 汐 | TideBar | 应用名称；目录、仓库与代码标识使用 TideBar。 |
| 汐线 | Tide Line | 任务栏收起时显示的细线。 |
| 图标栏 | Icon Bar | 任务栏展开后显示条目的区域。 |
| 条目 | Item | 图标栏中的一个操作入口，可以是应用、文件、文件夹或小工具。 |
| 固定项 | Pinned Item | 用户添加并持久保留的资源引用；取消固定不删除原文件，也不退出应用。 |
| 临时项 | Temporary Item | 未固定的运行中应用在图标栏中的条目，应用退出后移除。 |
| 潮涌 | Surge | 长按或 Option-click 条目打开的面板。内容由条目类型决定，例如应用的窗口列表、文件夹的最近文件。 |
| 窗口状态点 | Window Dots | 应用图标下的窗口标记。实心表示未最小化，空心表示已最小化，强调色表示当前聚焦，淡化表示位于其他显示器；窗口超过五个时显示总数。 |
| 通知角标 | Notification Badge | 从系统 Dock 读取并显示在应用图标上的数字或圆点。 |
| 涟漪 | Ripple | 有新角标后，汐线持续播放的提醒动画。展开图标栏或全部角标消失时停止；展开不会将原应用中的消息标为已读。 |
| Dock 接管 | Dock Takeover | 保存并修改系统 Dock 设置以隐藏其入口，同时启用 TideBar 底部任务栏。恢复设置或正常退出 TideBar 时结束接管。 |
| 小工具 | Widget | 带有自身内容和操作的条目，例如应用收藏夹。 |
| 应用收藏夹 | App Collection | 保存一组应用启动入口的小工具，支持多个实例；不显示组内应用的运行或窗口状态。 |
