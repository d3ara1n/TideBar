# 汐 TideBar

一款开源的 macOS 窗口任务栏。闲置时收起为屏幕底部的一条细线，鼠标靠近时展开，用于启动应用、切换窗口和恢复最小化窗口。

[English](README.md) · 简体中文

[下载](https://github.com/d3ara1n/TideBar/releases) · [官网](https://tidebar.dearain.dev) · [问题反馈](https://github.com/d3ara1n/TideBar/issues)

## 功能

- 启动应用，按窗口标题切换到指定窗口，包括恢复最小化窗口。
- 在应用图标下显示窗口状态：实心点表示未最小化，空心点表示已最小化，强调色表示当前聚焦窗口。
- 固定应用、文件和文件夹，拖拽调整顺序；在文件夹的弹出列表中打开最近修改的项目。
- 创建应用收藏夹，分组保存应用启动入口。
- 显示来自系统 Dock 的应用通知角标。有新角标时细线播放提醒动画，展开图标栏后停止。
- 支持键盘操作、多显示器，以及外观和全屏行为设置。

## 安装

需要 **macOS 14 或更高版本**。

1. 从 [Releases](https://github.com/d3ara1n/TideBar/releases) 下载 `TideBar-<version>.zip`。
2. 解压后将 `TideBar.app` 移到「应用程序」。
3. 打开 TideBar。当前构建未经 Apple 公证；如果 macOS 阻止打开，请在尝试启动后，进入「系统设置 → 隐私与安全性」，选择「仍要打开」。
4. 按首次启动引导授予辅助功能权限，并启用 Dock 接管。

TideBar 会在菜单栏显示图标，可从菜单打开设置或退出。

### 系统 Dock 设置

启用 Dock 接管时，TideBar 会保存现有 Dock 设置，修改设置以隐藏 Dock，并重启 Dock 进程。修改也包括 Dock 图标大小和最小化动画，已打开的应用会继续运行。

只有启用接管后，TideBar 才显示底部任务栏。在「设置 → Dock 与恢复」中可以停用任务栏并恢复保存的 Dock 设置。正常退出 TideBar 也会恢复；崩溃或强制结束进程可能留下已修改的设置，此时重新打开 TideBar，通过同一设置页恢复。

## 基本操作

| 操作 | 效果 |
|---|---|
| 鼠标靠近底部细线 | 展开图标栏，移开后收起 |
| 点击应用 | 启动应用或切换到最近的窗口；若窗口均已最小化，则恢复一个窗口 |
| 长按或 Option-click 应用 | 打开窗口列表，点击标题切换或恢复该窗口 |
| 右键点击应用 | 固定或取消固定、在 Finder 中显示、显示或隐藏窗口、退出应用 |
| 从 Finder 将应用、文件或文件夹拖到图标栏空隙 | 固定到任务栏 |
| 在栏内拖动固定项，或将它拖出栏外 | 调整顺序或取消固定；取消固定不删除原文件，也不退出应用 |
| 点击已固定的文件或文件夹 | 通过 macOS 打开 |
| 长按或 Option-click 文件夹 | 按修改时间列出其中的项目，最近修改的排在前面 |

从 Finder 将文件拖到**应用图标上**，会用该应用打开文件，前提是应用支持该文件类型。拖到**文件夹图标上**则会将文件移入该文件夹；仅支持同一宗卷内移动，不覆盖已有文件。

### 键盘操作

| 默认快捷键 | 操作 |
|---|---|
| Option-Space | 显示或隐藏图标栏，进入键盘导航 |
| Option-Tab | 循环选择应用，停止操作一小段时间后激活选中项 |
| 左 / 右方向键 | 选择应用 |
| 下方向键 | 打开所选应用的窗口列表，随后向下选择窗口 |
| 上方向键 | 在窗口列表中向上选择 |
| Return | 激活选中项 |
| Escape | 关闭窗口列表；在应用层级时取消导航 |

在「设置 → 快捷键」中修改全局快捷键和切换延迟。键盘导航支持应用及其窗口。

全屏应用下，默认需要点击底部细线才能展开。在「设置 → 外观与交互」中可改为鼠标靠近时展开，或完全隐藏。

## 权限与限制

- **辅助功能**用于读取窗口标题与状态、聚焦和恢复窗口、识别全屏应用，以及读取 Dock 角标。未授权时仍可启动应用，但窗口管理受限；部分应用无法提供可用的窗口信息。
- 不显示窗口缩略图，不申请屏幕录制权限。文件访问遵循 macOS 的访问控制。
- 无账号系统，不收集使用情况或行为分析数据。打包版通过 Sparkle 从 GitHub Releases 检查更新，可在「设置 → 关于」中关闭自动检查。
- 不提供废纸篓或应用专属的 Dock 菜单。图标栏展开时覆盖在窗口上方，不调整窗口大小。

## 从源码构建

需要 macOS 和 Swift 6.2 或更高版本的工具链。克隆仓库后编译并运行：

```bash
git clone https://github.com/d3ara1n/TideBar.git
cd TideBar
swift build
swift run
```

运行期间保持终端打开，通过 TideBar 菜单栏菜单退出，以便恢复 Dock 设置。开发可执行文件与打包版应用需要分别授予辅助功能权限。检查更新和登录时启动仅在 `TideBar.app` 中可用。
