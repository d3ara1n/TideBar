# 汐 TideBar

**平时是一条线，需要时每个窗口触手可及。**

汐是一款 macOS 不占屏幕的窗口任务栏。平时，它只是屏幕底部一条若隐若现的细线；光标靠近，便如潮汐般展开为图标栏——每个窗口的状态点点可见，点击即达。按住任意图标（或 ⌥+点击），「潮涌」展开该应用的全部窗口，连最小化的也能一键还原。开启接管，系统 Dock 隐去，屏幕底部只剩这条线，小屏 MacBook 也能多出一整行空间。

## 核心功能

### 汐线 · 不占屏幕

空闲时是贴着屏幕底边的一条 2–3pt 细线，随浅色／深色模式自适应，几乎不可见；光标靠近即潮汐般展开为图标栏，离开即收。

### 点点 · 窗口状态可见

图标下的小点如实反映窗口：实心是活跃窗口，空心是最小化。回答的不是「哪些 app 在运行」，而是「每个窗口在哪」。

### 潮涌 · 直达任意窗口

按住（或 ⌥+点击）图标展开窗口列表，按窗口标题直达，最小化的点击即还原。隐藏 Dock 后无处安放的最小化窗口，在这里有了落点。

### 涟漪 · 克制的通知

新角标到达时细线轻涌一次；未被查看就持续微微荡漾，展开即确认。不靠抢占注意力说「有事」，靠持续在场说「还没看」。

## 权限与隐私

- **只要一项权限**：辅助功能——用于列出与还原窗口，以及识别全屏状态。
- **不申请屏幕录制**：汐不显示窗口缩略图，也不申请屏幕录制权限。
- **无遥测**：无追踪、无账号、无行为分析。

## 安装

从 [Releases](../../releases) 下载最新的 `TideBar.app`，拖入「应用程序」即可。要求 **macOS 14** 或更高版本。

### 从源码构建

```bash
swift build    # 编译
swift run      # 本地运行（占用终端，Ctrl-C 退出）
```

需要 Swift 6.2 及以上工具链，最低支持 macOS 14。
